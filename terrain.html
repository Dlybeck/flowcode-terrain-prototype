Reading this map

      
The project summit groups entry points. Its spokes show membership, not runtime calls. A terrain branch uses one possible caller for placement; other callers remain available when you select a function.

      
Among siblings compares the next choices of one caller. Project-wide uses one relevance scale across the selected source. Neither is a measure of execution time or proof of importance. A sole child receives a neutral drop in sibling mode.

      
Unplaced does not mean unimportant. Points outside the mountain have no established path from an entry in this analysis. Their display height is not a relevance score. They remain searchable, with all known callers and callees.

      
Essential keeps only real functions as markers. A solid connection can condense less-important intermediate functions while preserving their original call order. Select its endpoint to reveal that complete path. Scores and cumulative drops come from the complete graph.

      
Complete-view overview shows spaced markers. Zoom in to reveal nearby functions, or choose All nodes. The complete terrain, relevance scores and call graph stay the same. Selecting a function reveals every caller along its primary path; search always includes the full inventory.

      
Solid lines follow a branch; dotted arrows show extra calls. Gold highlights your selected path. Select a node to inspect its calls or project membership. By default, only extra calls touching the selected function are shown. Static analysis includes alternatives, not a chronological runtime trace.
